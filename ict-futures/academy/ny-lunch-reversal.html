New York Lunch Algorithmic Reversal (community label)

A community label for a possible midday reversal narrative. It is not a core model in the supplied playbook, which explicitly treats the NY lunch window (12:00–1:30 PM ET) as an avoid period.

How to identify and use this concept

  1. Read the supplied playbook’s NY lunch caution before studying this label.
  2. If researching historically, predefine the instrument, date range, session boundaries and reversal trigger.
  3. Separate ordinary low-liquidity chop from a genuine structure shift.
  4. Record spread, slippage and event context; do not treat the label as a live signal.
Use only as a research hypothesis for historical testing, not as a recommendation to trade lunch.

Common mistakes and limitations

Ignoring the PDF’s avoid guidance; assuming an algorithmic mechanism; inferring predictable reversals from a named pattern.
